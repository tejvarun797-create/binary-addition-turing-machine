Binary Addition Using Turing Machine

Theory of Computation · Interactive Project Demonstration

Enter Binary Numbers

Enter only 0 and 1. Example: 101 + 011 = 1000.

Step-by-Step Turing Machine Simulation

Reading proceeds from right to left (least significant bit first). Missing bits are treated as 0.

StepRead ARead BCarry InWrite BitNext State

q0 means carry = 0   q1 means carry = 1   qhalt means computation finished.

How This Model Works

  1. Tape 1 stores the first binary number.
  2. Tape 2 stores the second binary number.
  3. Tape 3 stores the result bits.
  4. The machine adds one pair of bits at a time, moving from right to left.
  5. The carry determines whether the machine is in state q0 or q1.

This is an educational Python-free browser simulation of the same three-tape Turing Machine-style addition logic.
